# Поля команды и запроса HIT-113

| Вход или поле | Источник и проверка |
| --- | --- |
| Workspace, case | Параметры существующего `recoverCase`. В SQL выбираются по UUID области RLS и серверному owner из IAM. |
| Session, CSRF, права | BFF mTLS, один заголовок сессии и CSRF, актуальные IAM `CASE_RECOVER` для case и `CONNECTOR_READ` для принятого подключения. Общий startgate HIT-69 учитывает отзыв. |
| Action, revision, command ID | Строгая схема `RecoveryCommand`. Допущен только `RECHECK`. Ревизия обязательна, `If-Match` при наличии совпадает. `X-Request-ID` совпадает с `command.request_id`. |
| Повтор и причина | Ledger хранит scope, owner, исходную ревизию, фиксированный итог принятия и SHA-256 канонического JSON. Причина хранится в expiring HISTORY. Повтор проверяет тело и scope. |
| `DeliveryQuery.workspace_id`, `case_id` | Из сохранённого дела и команды. |
| `DeliveryQuery.lineage_id`, `native_task_id` | Из сохранённой identity под fence. HIT-79 HISTORY подтверждает связь lineage и исходного эпизода. Native ID в пользовательском запросе служит проверкой совпадения. |
| `DeliveryQuery.expected_connection_epoch` | IAM при принятии. Фактический старт требует текущий допуск с той же эпохой. |
| `DeliveryQuery.deadline_at` | Фиксируется из времени SQL при принятии. До 30 с с ограничением по сроку доказательства lineage. Аренда и timeout ограничивают отдельную отправку. |
| Служебные поля | Ревизия дела, связанный эпизод, операция, конфигурация, её digest, owner и подключение хранятся в файле outbox. Они проверяются перед отправкой. В принятый wire входят только шесть полей `DeliveryQuery`. |
| `TaskObservation` | Строгий HIT-99 JSON и digest по mTLS. Дополнительно сверяются область, case, lineage, episode, task ID и временное окно запроса. Ревизия, доказательство, конкурентные и поздние наблюдения обрабатываются существующим HIT-99. |
| HTTP 202 и чтение дела | После собственного commit отдаётся `CaseDetail`. Состояние, знание и ссылка определяются сохранёнными наблюдениями. Принятие повторной проверки записывается в историю отдельно. |
