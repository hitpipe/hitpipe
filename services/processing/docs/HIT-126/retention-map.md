# Карта очистки HIT-126

Основания: действующий контракт HIT-126, HP-MVP-A-005/025/026, GLOBAL_NFR, HP-MVP-SQL-PROCESSING и их закреплённые версии из `source-audit.json`.

| Объект | Источник срока и владения | Действие |
| --- | --- | --- |
| `CASE_CONTEXT` | Origin workspace и непрозрачный ref файла, `case_content.expires_at` | Удалить истёкшие байты, если ни одна известная SQL-ссылка в workspace не остаётся актуальной. Оставить метаданные для действующего признака `context_expired`. Принятый потолок хранения контекста — 90 суток. |
| `HISTORY` | Origin, `history_content.expires_at`, проверка совпадения `safety_history.proof_ref` | Удалить истёкшее тело. Сохранить минимальную историю, её время и происхождение. Если отдельный safety proof совпал с именем файла и его срок не доказан, файл удерживается. Принятый потолок обычной истории — 90 суток. |
| `DRAFT_DATA` | Origin, сопоставление `drafts.prose_ref` и обоих SQL-сроков, собственный срок каждого файла | Очистить просроченный корень и собственные просроченные фрагменты. Сроки и политики HIT-100/HIT-102 остаются источником для чтения. Нулевой или расходящийся актуальный SQL-срок блокирует удаление связанного корня. Запись idempotency не удаляется. |
| `DELIVERY_INTENT`, `DELIVERY_QUERY` | Origin, сохранённый `outbox.expires_at`, состояние и lease | Просроченные `PENDING` / `CLAIMED` становятся `HELD` отдельным коммитом до удаления. Очищаются только lease/claim, сохраняются message ID, digest, счётчик доставок, lineage и знание внешнего эффекта. `ACKED`, уже удержанные сообщения и состояния дела сохраняются. |
| Сирота и `.pending` | Защищённый заголовок собственного файла, исходный срок, фактическое отсутствие актуальной SQL-ссылки | До срока сохраняется даже при неизвестном исходе SQL-коммита. После срока перепроверяется под блокировками. Запись с неопределимым происхождением или сроком остаётся для ручного разбора. |
| Стабильные данные безопасности | `case_identity`, `safety_history`, `inbox`, `user_commands`, config, episode, fence/lineage и минимальные метаданные outbox | Сохраняются. Пустой или истёкший файл не является доказательством. Повтор не продлевает срок и не снимает защиту от нового create. |

Очистка ограничена файлами Processing. Принятые сроки для Intake, других сервисов, рабочих секретов и восстановления копий не являются параметрами этой команды. Физические байты удаляются отдельно от сохранённых непрозрачных ссылок и сроков, поскольку их читает существующая минимальная история и признаки истечения срока. Нормативный SQL и OAS сохранены.
