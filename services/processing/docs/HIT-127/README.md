# HIT-127. Операционная диагностика Processing

Codex по делегации Тимофея Патрушева (Tim1hik). Закреплённая редакция 1. [Карточка HIT-127](https://hitpipe.atlassian.net/browse/HIT-127) · [Draft PR №82](https://github.com/hitpipe/hitpipe/pull/82).

Код `f1ddceeda0a61b7a7fd58a79d9b3616d4d614702` проверен на локальном одноразовом PostgreSQL 18.7. Основа `d450efc7cfc11f8155a476304aced96dad0ebaf6` включает подтверждённые версии HIT-111–114 и HIT-126. Их PR остаются открытыми. `main` зафиксирован отдельно в [аудите исходников](source-audit.json).

| № | Критерий | Фактическое наблюдение |
| --- | --- | --- |
| 1 | Источники, интервал и смысл | SQL-снимки берутся из собственных таблиц. Возраст наблюдения публикуется после нового коммита. [Карта показателей](diagnostics-map.md). |
| 2 | Реальные задержки, HOLD и UNKNOWN | Реальный снимок показал 2037 мс inbox, 2034 мс outbox, 2034 мс jobs. После RECHECK записан HELD, после контролируемых SQL-транзакций изменились ряды outbox и jobs. UNKNOWN сменился ATTENTION после принятого mTLS Observation. Измеренный возраст наблюдения 708 мс. Повтор HTTP 202 метрику не продублировал. |
| 3 | Различимые причины и непрозрачные ID | В процессных логах отдельно видны CLOSED/OPEN, истёкшая аренда, ошибки PostgreSQL, файлов, индексации после перезапуска и отказ команды очистки. Разрешённые case/message/effect IDs сверены. Маркеры учётных данных, внешнего аккаунта и тела отсутствуют в захваченном выводе. |
| 4 | Бюджет и scope | Прогнан предел 100 при 107 строках. Запись другого workspace и job вне scope в выборку не попали. App role отклонена, диагностическое чтение read-only. Ограниченная частота событий и UUID-проверка прошли отдельный race-тест. |
| 5 | Точная Health | На том же CLI и mTLS проверены CLOSED, READY и DEGRADED при реальном отказе подключения worker. Обработчик побайтно совпал с базой. Технический READY одновременно наблюдался с HELD и ATTENTION. |
| 6 | Настоящие проверки | Проверены PostgreSQL, TLS/mTLS, файловый отказ, SIGKILL/перезапуск, повторное чтение устойчивого состояния и штатное завершение. Host Go 1.27.2 race/vet/build и CI 6/6 прошли. |
