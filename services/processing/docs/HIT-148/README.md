# HIT-148. Адресное удаление подробностей дела в Processing

Codex по делегации Тимофея Патрушева (`Tim1hik`). [HIT-148](https://hitpipe.atlassian.net/browse/HIT-148).

**Статус: BLOCKED.** В проверенных источниках не найден подтверждённый допуск на удаление конкретного дела. Адресный режим не добавлен. Рабочие данные не открывались. На выделенном стенде проверена существующая очистка по сроку хранения. Изменения этой ветки ограничены отчётом и журналами.

[Проект CCR для Lead](CCR_CASE_DELETION_AUTHORITY_RU.md) · [Повторная проверка принятых контрактов и реализаций](authority-source-audit.json). Проект уточняет источник и правило повторного применения решения, необходимые для исполнения четырёх критериев.

## Что требуется от Lead

Укажите принятый источник и способ чтения подтверждённого owner-local решения на удаление содержимого одного дела. Нужны владелец источника и закреплённая ссылка на договор, однозначная привязка решения к `workspace_id` и `case_id`, признаки подтверждения и актуальности для требуемого поколения, а также правило получения и повторного применения решения при восстановлении до открытия обслуживания. Отдельно укажите, как безопасно отличить завершённое удаление при повторе и прочитать минимальное состояние после него. Если такого источника ещё нет, нужен формальный маршрут его согласования.
