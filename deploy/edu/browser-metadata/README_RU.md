# Учебный каталог Stripe и ClickUp

Адаптер возвращает разрешённые подключения и варианты для одной рабочей области. Сторона, запускающая адаптер, передаёт подтверждённые привязки рабочего пространства через `ready` и время фактической проверки через `observe`. При недоступности проверки адаптер отвечает HTTP 503. Сертификат клиента и сессия проверяются при каждом запросе.

В учебном режиме без `ready.providerDemo` показываются прежние локальные имитации. Для выделенной рабочей области с настоящим Stripe Sandbox и тестовым списком ClickUp сервер добавляет `ready.providerDemo`. В объекте нужны ровно шесть строковых полей.

| Поле | Значение |
| --- | --- |
| `sourceAccount` | Идентификатор аккаунта Stripe Sandbox |
| `sourcePrice` | Идентификатор согласованного тарифа Stripe |
| `destinationWorkspace` | Идентификатор рабочего пространства ClickUp |
| `targetList` | Идентификатор выделенного списка ClickUp |
| `assignee` | Идентификатор исполнителя |
| `label` | Точная подпись услуги, используемая в принятой конфигурации |

В обоих профилях используется режим `TEST`. Для выделенной области интерфейс показывает «Stripe Sandbox» и «ClickUp · HitPipe Demo». Подпись выбранного тарифа совпадает с требуемой подписью услуги. В сборке с редактируемым полем «Подпись услуги» перенесите её в это поле перед сохранением черновика.

В `ready.providerDemo` передаются идентификаторы и подпись. Ключи провайдеров остаются в сервисах, которые выполняют запросы. Успешный запуск каталога подтверждает доступность настроек. Активированную операцию и подтверждённую задачу проверяют отдельным сквозным прогоном.

Проверка адаптера запускается командой `node --test deploy/edu/browser-metadata/metadata.test.mjs`.
