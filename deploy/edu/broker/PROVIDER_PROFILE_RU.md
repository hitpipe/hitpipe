# Stripe Sandbox и ClickUp для одной рабочей области

Оператор передаёт брокеру `--provider-profile /полный/путь/provider-profile.json`.
Обычные параметры `--registry`, `--ready-root` и `--binaries` сохраняют прежние значения.
Выбранный UUID берётся из реестра подтверждённых учётных записей. Параметры браузера
на выбор рабочей области не влияют.

| Поле профиля | Значение |
| --- | --- |
| `workspace_id` | UUID зарегистрированной рабочей области. |
| `state_root` | Новый отдельный короткий каталог, например `/home/deploy/.hp-school/pdemo`. |
| `binaries` | Каталог отдельной сборки с четырьмя исполняемыми файлами и `binaries.sha256`. |
| `binding` | Файл с полями `sourceAccount`, `sourcePrice`, `destinationWorkspace`, `targetList`, `assignee`, `label`. |
| `credentials` | Файл с ключами для процесса, обращающегося к Stripe Sandbox и ClickUp. |
| `webhook_secret` | Файл с секретом проверки подписи вебхука Stripe Sandbox. |

Укажите канонические абсолютные пути. Профиль, настройки и секреты лежат
в файлах с режимом `0600`. Их родительские каталоги, каталоги сборки и состояния
принадлежат пользователю брокера и имеют режим `0700`.

При первом переключении остановите только прежний экземпляр выбранной рабочей
области, `hitpipe-school-tenant-<slug>.service`. Брокер с новым профилем создаст
ему отдельный каталог и том PostgreSQL с именем экземпляра `d<15 знаков slug>`.
Старый том `hitpipe-school-pgdata-t<15 знаков slug>` и его файлы остаются доступны
для возврата к учебному режиму. Другие учебные экземпляры продолжают использовать
прежние каталог и сборку. Не останавливайте их для переключения выбранного профиля.

Файл готовности выбранной рабочей области остаётся по прежнему пути
`<ready-root>/<slug>/gateway-ready.json`. Брокер публикует его, когда проверит
совпадение закреплённых Stripe и ClickUp, выключенный учебный платёж, действующую
сессию и её право работать в выбранной области.

Для возврата к учебному режиму снимите параметр профиля при перезапуске брокера
и остановите только экземпляр выбранной рабочей области. Брокер поднимет старую
сборку со старым томом. Данные демо при этом остаются в отдельном томе. При повторном
включении с тем же профилем брокер поднимет этот демо-том.
