Утилита `peer_metrics.go` просматривает тела функций четырёх файлов из diff. Сложность — единица плюс if, циклы, недефолтные case и токены && и ||. Для дублирования сравниваются окна из пяти строк в одном теле функции после лексического разбора. Пустые строки, строки только со скобками блока и комментарии исключены, имена и литералы сохранены. Совпадения ищутся отдельно в производственном и тестовом коде, дублированные строки считаются однократно. Результат 0 совпадений в четырёх файлах не исключает небольших или смысловых повторов. Два повтора настроек HTTP-запроса разобраны в ревью, обработка общего ответа уже вынесена в readJSON.
