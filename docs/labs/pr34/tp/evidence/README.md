## Прогоны

Тройки файлов `*.json`, `*.stdout` и `*.stderr` содержат результаты реальных запусков на Darwin/arm64. Пустой поток является фактическим пустым выводом. `${WORKSPACE}` в опубликованной копии обозначает заменённый префикс локальной папки. Время, пути внутри рабочей папки, аргументы и коды выхода сохранены. Независимо от расположения рабочей копии команды выполняются из `services/processing`; Go 1.27.2 и Staticcheck 2026.2.2 должны быть в PATH. Для генерации нужны закреплённая OAS и `gofmt` из того же Go.

Логи `ci-*.log` содержат неизменённые строки проверки GitHub Actions для checkout, пакетного тестирования, vet и Staticcheck. Метаданные получены через `gh run view <id> --repo hitpipe/hitpipe --json name,headBranch,headSha,event,status,conclusion,url,jobs`. Снимки сделаны в Chrome с представления сохранённых локальных и серверных журналов. На снимках CI оставлены строки, показывающие состояние и результат выбранного шага. Полные прогоны доступны на GitHub.

Для повторения расчёта из `services/processing` используется `go run ../../docs/labs/pr34/tp/evidence/metrics.go -source internal/adapters/intake/sourcefacts/projection.go`. Инструмент считает токены тел функций: ключевые слова и знаки операций — операторы, идентификаторы и литералы — операнды. Скобки, точки, запятые, точки с запятой и комментарии исключены. Для сложности считаются `if`, циклы, недефолтные ветви `case`, `&&` и `||`. Таблица `metrics-manual.tsv` перечисляет токены вручную по строкам `decodeFields`, в сумме 53 оператора и 120 операндов. Хеши опубликованных материалов указаны в `sha256.json`.
