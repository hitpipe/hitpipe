# CR-001 · перевод PostgreSQL с 18.6 на 18.7

**Автор учебной формулировки и ответственный за решение — Дмитрий Карачебан, руководитель HitPipe.** Учебное согласование действует по заранее установленному разрешению преподавателя, о котором сообщил лид. Техническое основание — [HP-ADR-010](https://hitpipe.atlassian.net/wiki/spaces/Hitpipe/pages/24608769). Закреплённые версии исходников после QE перечислены в [манифесте](manifest.json).

**Обоснование.** Для HitPipe версия PostgreSQL 18.7 фиксирует исправление безопасности и общую основу для миграций и проверок. Отчёт ссылается на ADR для исторического обоснования и отдельно приводит доказательства, полученные самим участником. [Информация об исправлении PostgreSQL](https://www.postgresql.org/support/security/CVE-2026-120154/)

**Требование.** Проверить используемую версию PostgreSQL и затронутое поведение своего модуля на 18.7. Работать на изолированном стенде с тестовыми данными и сохранить версию до и после изменения, если выполнялся сравнительный прогон. Если модуль работает через API, проверять поведение через его штатные границы. Версию базы подтвердить отдельным протоколом стенда. Учебный скрипт бэкенда после QE проверяет версию 18.7 и настройки хранения данных. [Проверка при запуске](https://github.com/hitpipe/hitpipe/blob/e8f6415dc30169de18b9c971d440f790eb6da583/deploy/edu/backend/run-school-backend.sh#L145-L148) Для проверок исходной версии достаточно безопасной диагностики и сравнения поведения на тестовых данных.

| Где применить | Что приложить |
| --- | --- |
| МДК 01.04 № 3 | Матрицу пяти свойств системных границ по разделам 2.5 и 4.6 методички. Для каждого свойства указать критерий, проверку, фактический результат и источник. |
| МДК 01.04 № 4 | Замеры выбранного модуля после CR-001 с зафиксированной конфигурацией. |
| МДК 03.02 № 4 | Матрицу критериев CR-001, соответствующие проверки ПР 2, риски, результат Quality Gate v1 и повторный прогон затронутых сценариев. |

Общий файл CR фиксирует изменение. Каждый исполнитель прикладывает собственные подтверждения и отмечает ограничения, которые влияют на его выводы.
