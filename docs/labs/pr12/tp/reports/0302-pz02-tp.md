Материалы 01 04 ПР2

Отдельное приложение соответствующей методички. Полный самостоятельный экспорт 0104-pz02-tp.docx прилагается; согласие преподавателя на объединённую сдачу не предполагается.

Самостоятельный экспорт 01.04 ПР2 сохраняет контракт pure evaluator и application EvaluatePaidOrder. File и finite double подключены к одному SourceFactsReader consumer; normal/error/expiry boundary проверены без смены потребителя. Typed outcomes, precedence, ownership, one read/no retry и отсутствие IO/state в domain документированы. Provider/source authenticity этим не доказана.

Личная module map и imports сверены на принятом main ec0dcba7ca42. A→B означает source import; cmd→application/adapters/domain, sourcefacts→application/input, application→domain. Реальные Intake/transport/storage остаются планом, чужая работа не приписана. Два направления: nullable/exact financial data и bounded snapshot interaction; module ADR сравнивает handler/shared helper/service-local policy и цену типов, копирования и interface call.

Новые local tests и Linux CI принятых инженерных изменений подтверждают bounded scope. Сохранены шесть мест для снимков; настоящее личное module peer review студента ещё HUMAN_PENDING. Техническое review Codex по поручению Lead и actual merge не подменяют этот gate; bottleneck/performance не измерялись.
