3 Ход работы

3.1 Контракт и документация до демонстрации реализации

| Часть контракта | Решение и источник |
| Назначение | Financial eligibility under already accepted policy; Evaluate / EvaluatePaidOrder |
| Вход | Immutable borrowed policy/facts, explicit now, supported schema1.0/evaluator paid-order-v1 |

| Ошибки/порядок | Shape/version → scope → unknown → invalid fact → freshness → financial checks; reader failure INCOMPLETE |
| Владение | Вход read-only на вызов; caller не мутирует конкурентно; result owned strings |

3.3 Подмена за одной границей без изменения потребителя

| Реализация | Как выбирается в точке сборки | Сценарий и результат | Ограничения доказательства |
| File | CLI composition; same reader port | normal VALID; expiry REFRESH; unknown INCOMPLETE | Offline file, не remote authenticity |
| In-memory double | TestReaderSubstitution parameter | те же expected и actual; no consumer rewrite | Finite test behavior; не production Intake |

Один EvaluatePaidOrder и один SourceFactsReader. TestReaderSubstitution вызывает неизменный consumer с File и finite in-memory double для normal/error/boundary/denial/read failure.
