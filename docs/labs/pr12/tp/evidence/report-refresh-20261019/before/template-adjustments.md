# Корректировки четырёх форм

HIT-32. Все четыре исходные формы из bootstrap v2 сохранены неизменными; SHA256 в reports/report-manifest.json. Это заполнение существующих форм, не новый произвольный дизайн. Школьный титул, таблицы преподавателя/оценки/подписи, стили, нумерация, section/page geometry, headers/footers сохранены. Неизвестные кафедра и группа явно не предоставлены; подпись/оценка не заполнены.

1. Пустые учебные инструкции заменены фактическими собственными requirements/code/test/CI/evidence и честными pending human gates. Facts, product decisions и empirical hypotheses разделены.
2. Одиночный mutation опыт старой формы представлен шестью отдельно компилируемыми defects; сохранены baseline/mutant/restored summary и добавлены actual diff/digest/build/test/first-failure/survivor/retest records. Natural count1 с настоящим red log; hidden suite not provided.
3. В 03.02ПР1 явно отделено приложение01.04ПР1 (toolchain/execution), в 03.02ПР2 — приложение01.04ПР2 (module/DI/map/complexity/ADR). Два самостоятельных0104DOCX сохранены. Согласие преподавателя на объединение не предполагается.
4. Слоты рисунков сохранены строго3/5/7/6, итого21. Только human placeholders и полный source/state/steps/cwd/command/SHA/visible/filename/caption/redaction/verification. Никаких generated/captured images; word/media отсутствует.
5. Содержательные таблицы расширены под фактические записи, строки клонируют формат исходной формы. Заголовки таблиц повторяются, строки не разрываются. Метаданные сокращены до читаемой ссылки на полные SHA в evidence; body содержит полные source/CI pins. Добавлены реальные hyperlink relationships.
6. Устаревшие номера страниц шаблонного оглавления удалены; оставлен outline действительных разделов без фиктивной пагинации. После вставки человеком изображений в Word обновить оглавление/поля и проверить окончательные страницы. updateFields=true сохранён. Повторяющаяся заметка о self SHA удалена из одного места во избежание отдельной страницы; правило осталось в тексте и submission-record.
7. Package comparison: изменены только document.xml, document relationships, core metadata и при необходимости settings/updateFields. Все preserve-only styles/numbering/themes/headers/footers retained byte-for-byte. Реальная bundled LibreOffice conversion в PDF прошла; текстовые границы проверены pdfplumber, выходов за страницу0. PNG/скриншоты не создавались по явному запрету пользователя; визуальная page-by-page проверка НЕ ЗАЯВЛЕНА и остаётся человеком. PDF internal QA, не сдаваемый отчёт.
