Пользователь HitPipe принимает правило Stripe Checkout → ClickUp. Intake устанавливает факты источника; Processing проверяет финансовую допустимость; Delivery исполняет отдельно разрешённый эффект и readback. Мой модуль PaidOrderEligibility реализует только вторую часть. VALID означает financial eligibility, но не admission, dispatch, current authority, состояние дела или успешный handoff. Обязательное ядро HP-VER-001 остаётся целиком в upstream/product/HP-DOC-PVL-001.md; локальная лабораторная реализует subset. TEAM, дополнительные packs, live connectors, полный lifecycle, authorization/epoch и provider effects остаются за её пределами и не объявляются необязательными для продукта.

Нормативные inputs: Shared HP-RULE-006/011/012, CAP-002 FR103; BP002/T004; BP003/T002/006/012; BP007/T005/010. Полный formal pin 84249ff3ba611358232294c46f6022f030ea223d. Чтение локальных immutable копий, а не latest Confluence. Shared устав, MVP, regulation и stack-decision — файлы ../shared/, их точные digests сохранены inventory. Discovery и Product source inventories имеют In Review/candidate; независимый исторический content review не превращается в наш human review.

Исходные synthetic data определяются до запуска: account acct_synthetic, Session cs_synthetic, Price price_fixed, amount 12000 minor units, currency usd, test mode, activation 2026-10-17T12:00:00Z, observation 2026-10-18T10:00:00Z, evaluation +5s. Reset — fresh value copy или перечитать versioned JSON; внешних записей и seed randomness нет. Fixture generator/spec в services/processing/testdata появится в HIT-27. Данные не являются customer samples.

Facts: действительные файлы/пины и явное решение Lead о pack. Product decisions: перечисленные ограничения RULE006. Hypotheses: реальные пользователи смогут предоставлять необходимые данные, форма будет понятной, фактическая доступность Stripe API достаточна.
