# Nikita Budykin report package

The four DOCX files are content-complete exports with status
`CONTENT_READY_IMAGES_PENDING`. They retain the four-lab structure required by
the report profile. Every required image remains a text-only manual placeholder;
the exact insertion instructions are in
`../evidence/screenshots/INSTRUCTIONS.md`.

The editable source modules are the Markdown/JSON files in the parent folder,
the Go module under `services/intake`, the evidence logs and the human-gate
protocols. Human review, merge, opposition, signatures, tags, screenshots and
defense remain outside the agent's authority.
