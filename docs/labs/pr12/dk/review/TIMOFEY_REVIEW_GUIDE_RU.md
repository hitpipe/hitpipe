## Действия Тимофея

Передай своему агенту [готовый промпт](TIMOFEY_AGENT_REVIEW_PROMPT_RU.md), дождись
итога и сообщи Дмитрию вердикт и ссылку. Открывать каждый PR, вручную выполнять
команды, переписывать журналы и нажимать Submit review не требуется: это поручено
агенту. Прежняя инструкция «сначала личные blind-ответы, потом агент-помощник»
заменена этим режимом для командного технического ревью.

У Tim1hik подтверждён admin-доступ к hitpipe/hitpipe. Восемь авторских PR #12–19
открыты; ревью на момент подготовки отсутствуют. Автор — dkar-dev.
Агент проверяет свой действительный GitHub account перед любой публикацией.
Право на репозиторий не доказывает, что авторизация уже есть на ноутбуке.

## Контекст без истории чата и VPS

Всё необходимое находится в репозитории: AGENTS.md, frozen Universal Master
Prompt, MANUAL_LAB_PR12 workflow, точные upstream copies, context-lock/source-files,
четыре методички, задачи, требования, код, авторские журналы, четыре DOCX и
[матрица 29 результатов](../criteria-crosswalk.json). Коннекторы Confluence/Jira,
эта переписка, авторская рабочая копия и SSH на VPS не нужны для анализа.

Агент сам получает текущие head/base всех PR. Полный комплект расположен на
head [PR #19](https://github.com/hitpipe/hitpipe/pull/19), а отдельные изменения —
в PR #12–18. Исторические SHA не выдаются за текущий review target. Exact источники
сохраняются до прогона, повторно сверяются перед отправкой вердикта.

[Текущее назначение](reviewer-assignment.json) отменяет NB → DK для командного
ревью Дмитрия. Frozen manifest и исторические evidence не переписываются.
Контракты Discovery/Product/Architecture остаются Candidate/In Review, grant=none.

## Что агент делает самостоятельно

1. Проверяет инструменты, идентичность и права; получает отдельный чистый checkout
   без изменения текущей работы Тимофея.
2. Читает нормативный контекст и реальные diffs всех восьми PR; сверяет код с
   требованиями, а не только с авторскими expected values.
3. Выполняет проверки пакета, frozen sources, IAM tests/vet/race, сборки/smoke,
   подстановку adapters, imports/Godoc, семь compiling mutations; сохраняет
   argv/cwd/время/full SHA/exit и настоящие журналы.
4. Проверяет четыре отчёта, все29 критериев и21 инструкцию снимков. При наличии
   renderer выполняет визуальную проверку; иначе честно ограничивает вывод.
5. Публикует evidence и замечания, настоящее GitHub review каждого проверенного
   PR и сводный результат #19. Обновляет HIT-23 доступным личным коннектором
   или сохраняет точный jira-update.md вместе с результатом.
6. Выдаёт APPROVED_FOR_SCOPE, CHANGES_REQUIRED или LIMITED_ENVIRONMENT.
   При замечаниях готовит одно полное поручение исправлений авторскому агенту.
   Merge, submission tags, Done и фазовая acceptance в этот запуск не входят.

Подробные команды, критерии и правила публикации — в
[промпте](TIMOFEY_AGENT_REVIEW_PROMPT_RU.md).
[Форма результата](TIMOFEY_REVIEW_RESULT_TEMPLATE.md) не содержит готового PASS.

## Различия машин и только необходимые вмешательства

| Ситуация | Действие агента | Когда нужен Тимофей |
| --- | --- | --- |
| Другая машина, пустая история | Получить репозиторий и frozen context | Не нужен перенос чатов |
| Нет Go 1.27.2/компилятора/make | Подготовить доступный user-local toolchain либо выполнить существующий IAM workflow в GitHub Actions на текущем head | Если среда и сеть запрещены политикой и CI тоже недоступен |
| Windows без WSL/GCC/readelf | Использовать существующий Ubuntu workflow для test/race/mutations/smoke; оставшиеся локальные проверки обозначить точно | Не требуется вручную устанавливать WSL ради начала ревью |
| Нет локального GitHub login | Использовать уже авторизованный GitHub connector/gh; проверить account | Однократный login/2FA, если действующей авторизации нет |
| Нет Jira connector | Читать frozen exports, опубликовать review в GitHub и jira-update.md | Для переноса комментария позже; анализ не останавливать |
| Sandbox/организационная политика запрещает операцию | Продолжить независимые проверки и запросить только конкретное недоступное действие | Только реально требуемое разрешение; настройки защиты автоматически не отключать |
| Нет DOCX renderer | ZIP/XML/text/table/link/placeholder проверка; visual NOT_RUN | Возможный последующий просмотр оформления, не ручной code review |
| Кончилась квота Codex/Actions | Сохранить checkpoint и честный промежуточный статус | Возобновление после доступности квоты |

Мы не проверяли настройки и login на машине Тимофея, поэтому отсутствие любых
вмешательств нельзя гарантировать заранее. Обычные технические действия агентные;
логины, 2FA и запрещённые политикой действия нельзя получить из текста промпта.

## Отдельные учебные действия

Личные student blind/clarity, peer/clean-room/module checks, интервью, оппонирование
другому проекту, настоящие снимки и защита **не являются предварительными шагами
этого технического ревью**. Агентный анализ не объявляется их личным прохождением.
Они остаются NOT_PERFORMED/NOT_CONDUCTED до действительных действий по методичкам.
Тимофей не должен вручную исполнять этот длинный учебный список, чтобы агент смог
начать и закончить командное ревью.

Публикация через аккаунт Tim1hik обозначается «Codex по делегации Тимофея»,
а не «Тимофей лично выполнил все команды». Решение о техническом scope отдельно
от готовности полной учебной сдачи и человеческих свидетельств.
