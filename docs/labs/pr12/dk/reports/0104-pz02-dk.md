### 3.3 Подмена за одной границей без изменения consumer

Один Service.Execute принимает SessionLookup. NewFile перечитывает строго синтетический JSON на Lookup, NewFixed хранит immutable value copy без IO; выбор в cmd, Execute unchanged. Оба adapter instances содержат один synthetic snapshot и игнорируют internal reference — они не multi-session production authority. FixedClock construction-time synthetic observation; file snapshot change не доказывает freshness этой clock. SystemClock с explicit HealthProbe отдельно; nil/false probe unavailable, CLI не вставляет fake true.

## 5 Заключение и индивидуальный вклад

Модуль имеет согласованный контракт, существенную проверяемую реализацию, production-oriented consumer и заменяемые synthetic adapters. Imports/ownership/effects/ошибки определены; две направления сложности и личный ADR позволяют продолжать IAM без переписывания этой порции. Код и документация готовы human review, полная сдача/приёмка/peer/защита не утверждаются. Профилирование и production integration явно остаются будущей работой.
