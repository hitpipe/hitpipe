## 2 Цель, проект и собственная часть

IAM проверяет существующий session snapshot как предварительное условие работы оператора. Services/iam имеет свой Go module; legacy root и чужие services не мигрировали. CLI принимает fixture path/format/adapter selection, выдаёт version/source metadata и fixed-code diagnostics; broken input даёт2, unavailable dependencies3, корректный denied0. Запуск read-only, без БД/LLM/аккаунта и production эффектов. Краткий источник решения — LAB-STACK-001, конкретные локальные варианты — DK-ADR-001.

### 3.2 Путь исполнения и состав артефакта

Go source + per-service go.mod/std library → Go1.27.2 typecheck/compile/link → linux-amd64 ELF с Go runtime → OS/runtime/main/run → Decode fixture/composition root → Execute Lookup→Clock→Evaluate → state/reason/exit. JSON input отдельно, Python/Git/gh/build tools для runtime не нужны. Binary содержит compiled Go/runtime/stdlib, а не interpreter/LLM dependency.

Actual `file`, `go version -m`, `readelf -S/-d` подтверждают статический ELF x86-64, .debug_info и отсутствие dynamic section в обеих сборках. CGO_ENABLED1 из build metadata не означает, что конкретный бинарник динамически связан. Сетевые библиотеки/authority/SQL в этом executable отсутствуют; cross-platform compatibility не измерялась.
