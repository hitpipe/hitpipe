# HIT-18 — значимое уточнение требований

Автор-владелец: Дмитрий Карачебан; техническая подготовка Codex. Предшественник: [HIT-17 / PR #12](https://github.com/hitpipe/hitpipe/pull/12), SHA `0661a3ea64bd9f5243a9a7f5b3e1195c31eef152`. Это кандидат, не merged/Accepted.

## Найденный пробел

R1 определяет normal/denied/unavailable и прямо оставляет для HIT-18 локальный порядок нескольких ошибок и точные временные границы. Upstream T/002 задаёт 8h/24h и отказ после истечения, но не требует от snapshot новой last-activity колонки и не назначает порядок безопасных reason codes. Реальный риск — считать now до медленного Lookup либо разрешить равенство deadline и получить иное решение в boundary case.

| До (R1) | После (локальный contract v2) | Проверяемое следствие |
| --- | --- | --- |
| «Истекшая сессия отклоняется» | now>=deadline; nanosecond boundary; оба срока обязательны | Три точки deadline−1ns / exact / +1ns для каждого срока |
| Несколько нарушений дают Denied, reason не определён | Полная таблица precedence; absolute раньше idle | Совпавшие дедлайны имеют один oracle |
| Trusted now как явный input | Zero/диапазон UTC 1..9999; malformed chronology; absolute ≤24h | Далёкая/неправильная дата не проходит через переполнение |
| Ports fail closed | Lookup → Clock → policy; Clock читается после IO | Spy/delayed Lookup с продвижением времени выявляет устаревший now |
| Неполный перечень dependency ошибок | Constructor nil/typed-nil; zero Service безопасен; фиксированные public reasons | Отсутствующая зависимость не паникует и не выдаёт Valid |
| Срок idle 8h известен из BP | Snapshot хранит готовый deadline, renewal вне scope | Не появляется ложное правило «idle всегда created+8h» и новая SQL-колонка |

## Принятое решение

Канонический локальный владелец — [module-contract.md](module-contract.md). Scope остаётся SessionPolicy/AuthenticateSession; formal OAS, IAM SQL, HP-VER-001 и общие архитектурные decisions не меняются. Уточнение обратимо, укладывается в HP-DELEG-001 AUTO и не требует нового выбора продуктовой стратегии.
