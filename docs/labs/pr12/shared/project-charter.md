# Устав учебного среза HitPipe

Владелец продукта и процесса: Дмитрий Карачебан. Основание: явное поручение Lead от 17.10.2026, не коллективная подпись и не интервью с заказчиком. Срок сдачи — 19.10.2026, Europe/Moscow; час преподавателем здесь не установлен.

HitPipe сопровождает бизнес-операции между сервисами до установленного результата либо понятного ожидания/исключения. Первый выбранный кандидатный pack — оплаченный поддерживаемый заказ Stripe → задача ClickUp. Источники: точные DA/Vision/Product/Architecture в upstream/, версии/дигесты — context-lock.json/source-files.json. Это принятые продуктовые решения Lead и опубликованные Candidate документы, не доказанный спрос и не Accepted contract.

Здесь делаем пять настоящих переиспользуемых частей: dk — SessionPolicy/IAM; nb — StripeSignature/Intake; tp — PaidOrderEligibility/Processing; ds — TargetReadback/Delivery; mg — CasePresentation/UX. Каждый владеет своим кодом и личными docs/labs/pr12/<code>/. Общими инструкциями/locks/инфраструктурой владеет Lead. Python AI service остаётся будущей областью; учебные задачи не меняют стек и не объявляют готовность AI/всей системы.

Готовность учебного среза: три содержательных code PR каждого, личные требования и инженерные документы, реальные исполняемые проверки и исправления, протоколы настоящих student/human checks, четыре покрытых методички, два основных отчёта 03.02 и два экспортных 01.04. Скриншоты вставляет человек по полным инструкциям. Нет разрешения на production effects/реальные платежи или deployment.

Этот устав даёт общий контекст, но НЕ заменяет личное обследование. Каждый студент получает реальные ответы пользователя/согласованного с преподавателем представителя и отдельно отмечает наблюдения, решения, гипотезы и неизвестное. Ответы Lead из предыдущих продуктовых поручений можно цитировать только с реальным происхождением; нельзя задним числом записывать их как проведённое студентом интервью.
