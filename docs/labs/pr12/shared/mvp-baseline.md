# Место учебных модулей в HP-VER-001

Полный положительный scope продукта находится только в upstream/product/HP-DOC-PVL-001.md; эта карта не создаёт второй MVP. Полный результат первой версии — согласованная постоянно действующая операция, доказательно проверенное назначение и сопровождение неполных/неизвестных случаев, с управляемой настройкой/активацией.

Путь: достоверный ingress → полный source proof/financial eligibility → разрешённый одноразовый owner-path → readback результата → честное представление case и доступного следующего действия. Session policy поддерживает доступ, не заменяет весь IAM.

Пять модулей — только пригодные для дальнейшей разработки части пути. Проверенная подпись не означает paid/admitted; финансовая допустимость не даёт права dispatch; совпадение synthetic target не является реальным ClickUp confirmation; UI snapshot не доказывает current authorization; локальная session policy не доказывает Keycloak/SQL/runtime barrier. Ничто здесь не объявляет весь сценарий готовым.

В каждой личной requirements.md: свой нормальный и существенный ошибочный результат, точные нормативные ссылки, обязательное ядро и резерв. Если учебная граница уже уже продукта, это subset, а не изменение HP-VER-001. Не реализуются live connectors, production endpoint, full Next migration и общий orchestrator только ради отчёта.
